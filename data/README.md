# Generated local data

This directory is for intermediate objects generated by the analysis, including:

- reduced female LV VCM Matrix Market counts
- SingleCellExperiment checkpoints
- PCA / UMAP / Harmony objects
- donor-level pseudobulk count objects
- edgeR fit/test RDS files

These files can be large and are excluded from Git by default. They should be regenerated locally from the public source data and scripts.
